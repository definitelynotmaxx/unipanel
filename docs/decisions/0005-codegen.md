# ADR 0005 — OpenAPI → TypeScript codegen

## Status
Accepted

## Context
The frontend and backend share DTOs. Hand-typing on each side invites drift.

## Decision
- The Rust server exposes `openapi.json` (utoipa) via a CLI command.
- The committed file is regenerated by `cargo run -p unipanel-cli -- openapi -o openapi.json`.
- `web/src/api/schema.d.ts` is generated by `npm run gen:api` using `openapi-typescript`.
- CI re-generates both and fails if committed files differ.

## Consequences
- One source of truth for the request/response shapes.
- No compile-time cross-language dependency.
- PRs touching routes or DTOs must include regenerated artifacts.
